# COグループ方式：比較候補の共同分布

現行の全配役一様と、残差だけの2段階試作を保全した比較候補。市民・霊能・狼、合計3〜9人。霊能能力・結果枝は含めない。心理的CO頻度や経験係数は使わない。これは公開盤面に対する明示的な解釈規則で、唯一の確率モデルという主張ではない。

## 初期スナップショット

配役人数、CO、騙れる役職、CCOを全員同時に検査し、合法な完全配置を求める。騙れる別役職を持つ役職群は、役職設定から抽出する。その群の**合法な位置配置を同時に**等重みにし、各位置配置の中で残る役職の合法配置を等重みにする。役職名・設定の走査順で優先順位を付けない。潜伏は未限定で、CO経路を重複カウントしない。

現在UIの設定では市民・霊能は役職騙りなし、狼は配役内の全役職を騙れる。内部関数は複数の騙り役職を同時に扱えるが、その設定変更UIは今回追加しない。

市民C・霊M・狼W、N人、霊COがk人なら、CO内狼jについて、CO内霊k−j、潜伏市民C、潜伏霊M−k+j、潜伏狼W−j。全て非負の候補だけを残す。候補jの重みは `binom(k,j) × binom(N−k,W−j)` を合法候補間で正規化。各狼配置の中の合法な市民・霊配置を均等に配る。実配役を1つ選ばず、Fractionによる共同分布を保持する。

| 5市民2霊2狼、CCOなし | CO内狼人数の分布 | 各CO者の狼率 |
| --- | --- | --- |
| 1CO | 0:7/9、1:2/9 | 2/9 |
| 2CO | 0:7/12、1:7/18、2:1/36 | 2/9 |
| 3CO | 1:6/7、2:1/7 | 8/21 |
| 4CO | 2:1 | 1/2 |
| 5CO | 候補なし、矛盾 | 表示しない |

定員到達CCOでは2CO以上で真霊全員が霊CO内に必要となり、各CO者の狼率は2CO=0、3CO=1/3、4CO=1/2。混在する市民CO・霊CO・狼COにも同じ互換・CCO制約を適用する。

## 編集と進行

- 初日昼の同一Board編集は、初期配役から完成したCOスナップショットを毎回再評価する。途中の編集順を時系列のCO発言と解釈しない。COを外せば現在の編集制約を撤回できる。
- 最初の行動時の共同分布を固定し、その後は既存の厳密な処刑・襲撃・終局分岐で確率を更新する。生存人数から配り直さない。開始からの既終局質量と未決着Boardの条件付き値は別に保持する。
- 後続PhaseのCO編集は、**保存された過去の各行動時COとCCO**を再生した分布へ現在COを条件付けする。新COによって騙り配置を等重みにし直さない。同じ後続Board内の編集順にも依存しない。現在COを取り除いても、過去のCO履歴で排除された配置は復活させない。過去の制約を変えるには戻って編集する。
- モデルは初日昼で切り替えられ、進行後は固定する。TOPから再開始すれば別モデルで比較できる。独立した初期盤面比較ページには現行／残差試作／COグループの3モードを残す。

初期A霊COでA狼2/9。潜伏Bが市民と判明した条件付け後もA狼2/9を確認（8人へ再配分した1/4にはしない）。通常の襲撃で「非狼」と判明することとは異なる観測なので、同じ数値を要求しない。

## 勝率と表示

共同分布から公開Actionの全候補を終局まで厳密評価し、その後に昼村max・夜狼max／randomを集約する。隠れた各配置で最適化してから平均しない。自噛み許可と計算包含は既存規則を維持。現在までのCO制約から評価し、将来のCO発言・霊能結果は自動生成しない。

MAINと比較ページにCOグループごとの市民・霊・狼人数候補と確率を表示。これは共同分布の射影で、別グループの確率を独立に掛け合わせない。

## 検証

直接回帰61件合格：承認分数、両狼1/36、質量1・人数・非負、CCO・混在CO・候補ゼロ、位置交換、複数騙り役職の設定順、同一COスナップショットの入力順、モデル切替、CO取消、進行・戻る・後続編集・履歴保全。小人数ではmax/random・自噛みを含め、状態共有しない全Tree評価と照合。

[9人実測](co-group-benchmark.json)：18条件、各条件で初期評価から未決着を選んだ手動履歴の終局まで評価。最大0.456693秒、最大Python割当ピーク959544 bytes。OSのRSSではない。同一公開状態のキャッシュを使い、近似値へ置き換えない。
