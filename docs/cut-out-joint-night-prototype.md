# Unconnected joint-night prototype

Scope: one fixed first-day execution (P3 or P1) from the actual seven-player public UNIFORM clone, then one night and its complete morning reports. No solve/act/Forecast recursion, UI/factory connection, MAX, hunter, new CO rule or strategy change. Files: cut_out_joint_night_prototype.py and its independent labelled test fixture.

## Generation before expansion

Admission issues an identity-bound NightCertificate from the existing root witness and one common fixed-death transition. It carries Q/public and P/physical separately. This is a deliberately narrow structural certificate: exactly one wolf among P1/P2, one among P5/P6/P7, P3 true medium, P4 initial white; the initial own scans and all saved root fields remain present. It is not an arbitrary-state symmetry detector.

produce uses block occupancy, a deterministic representative roster, live/legal target blocks and combinatorial multiplicity. It never constructs the literal wolf-information x target product and then deduplicates it, and never searches permutations or canonical keys. Representative information mass is summed from the supplied joint law and multiplied by the certified occupancy count; each target-block mass is its original uniform policy sum. The test makes wolf_information_groups and the old moved_law matcher throw during actual production.

labels lazily generates deterministic member transports only for output readback. A representative flow is evaluated once; labels do not re-run the acquisition/death/report kernel. Full role masks, acquisitions, initial/dead-owner records, attack histories, report vectors and public/physical Board facts are transported. Output expansion in the test is necessary to compare every named result, and is separate from successor generation.

## Exact local comparison

| Execute P3, Q=P | 24 | 18 | 3 | 85 | 720 |
| Execute P1, invariant P class weights 2/3 and 1/3 | 27 | 21 | 7 | 44 | 177 |

Thus the measured transition-generation saving is 21/20 versus the fully labelled oracle, or 15/14 versus current within-information-set target grouping. This is a count result, not an elapsed-time speedup or a bound on full-game size. The common kernel still generates its unchanged per-world ability/report histories inside each representative call; this prototype does not claim to optimize that kernel.

Both cases match the unaggregated common flow exactly after restoring every label: conditional public and physical probability Table rows, Q/P action-selection probability rows, total joint branch masses, entire public/conditional Q/private P role-and-secret laws, original wolf rosters, seer targets/colors including corpse targets, attacks, medium results and full seer report histories. Both Q and P total mass equal one. There are 276/24 restored leaf cases containing Day2 scans of corpses. No unknown history is filled, no roles are made independent, and false-report generation uses the existing configured common law.

The Table here contains labelled role and action/branch probabilities. It does **not** contain final win rates or action-value/horizon Forecast values. Those remain untested and are not presented as full Table/Forecast completion. SavedOrigin cold replay of an orbit transport and normal Table integration are also future work.

The Q!=P case is a declared synthetic physical measure for testing, not a new user observation or a change to the game's configured strategy. Executing P1 fixes the P1/P2 distinction, allowing unequal weights across those already separate classes while preserving uniformity within P5/P6/P7. Representative selection/legal uniform policy never uses those P weights; only physical mixture masses change. Conditional Q and P given a fixed roster are required to be exactly equal in this prototype. Arbitrary within-roster secret likelihood differences are refused/not supported.

Eleven negative cases reject copied/unissued certificate, one-sided skewed Q or P substitution, P skew breaking the still-intact P1/P2 block, non-exact weights, other/boolean prefixes, max, self/teammate or dead bite targets and unsupported wolf rosters. A positive Q!=P fixture is deliberately distinct from the forbidden non-invariant skew cases. Hunters are outside the only issuer's fixed H0 source; no hunter extension is inferred.

Three unit tests passed in 1.746 s, peak working set 50,159,616 bytes. Each local comparison has a five-second calculation budget; tests use the existing finite process memory watchdog. The refreshed fixture also passes the additional labelled action-probability rows. Canonical and CandidateRules calls are zero. No full initial Forecast was run.

## Conditions for a next stage

Only structurally issued fixed-prefix cases are supported. Before integrating, extend the receipt through generated observations with owner/revision and Q/P proof, prove legal/policy/physical equivariance for each admitted transition, preserve likelihoods under arbitrary eligible P, and add cold source/transport replay plus recursive <=3/<=5-live Forecast/action-value/Table/joint comparisons. Unknown correlation must stay unaggregated or unsupported. A scalar-equal branch alone is no certificate.

Runtime label restoration applies a previously constructed mapping; it does not test player exchanges to discover a group. The labelled oracle and all comparisons are fixture-only. No generic fallback, canonical grouping or initial-prior rebuild is introduced for child generation. Constructor's two history-validation passes remain unchanged as a separate cost. Heavy initial exploration remains deferred for coordination after Morishi's stability validation.
