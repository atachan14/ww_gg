# v0.2：公開Board、素村＋狼、3〜9人

2026-10-07。v0.1の3〜5人・狼1人の数値と操作を維持し、3〜9人・複数狼へ拡張。初期狼数は1〜floor((人数−1)/2)、初期値は5人・狼1人。初期から勝敗が決まる配役はTOPで選ばせず、送信改変も拒否する。

## 正本・導出値・キャッシュ

セッションに保存する正本は初期人数／狼数、固定ルール、現在戦略、手動対象履歴と各行動時の戦略。実配役や確率を保存・手編集しない。replayが初期盤面から公開履歴を適用し、生存者、Day／Phase、未決着条件付きBoardと既終局質量を再構築する。

Board.beliefは公開情報から導出された相関付きの厳密分布。整数ビット集合は「狼だった可能性のある位置集合」を表し、実配役の確定値ではない。可能な配置を全て重み付きで保持し、1つを選ばない。初期配役の人数制約、死者の情報、継続／終局の情報を保持する。残狼数分布、各位置の周辺確率、同時狼確率、勝率は導出値。wolf_countは分布が単一のときだけその値を返し、混合時はNoneとなる。

solve／symmetric_actionのキャッシュは再生成可能な評価値だけを保持する（各4096件上限）。キーは生存人数、Phase、位置相関を保持した生存者の同時分布、戦略。将来評価に関係しない死者の位置だけを周辺化する。表示用Boardは死者も含む分布を保持するので、死者の役職確率を失わない。

## 公開情報とChance

役職や残狼数は処刑時に公開しない。固定対象のAction後、各候補の勝敗をW=0なら村、W>=Vなら狼、それ以外なら継続として集約する。継続候補を一つの公開Boardにまとめ、継続質量で条件付ける。終局質量はProgressに保存し、現在Board条件付き値と開始時点からの累積値を区別する。

例：7人・狼2人でPlayer 1を処刑すると、6人生存の未決着Boardには1wが2/7、2wが5/7。自噛みなしでPlayer 2を襲撃して翌朝になると、5人生存でも1wが2/7、2wが5/7。Player 1の狼確率は2/7、Player 2は0、各生存者は12/35。二人の生存者が両方狼である確率は1/14で、(12/35)^2とは異なる。

自噛みRuleとStrategyは別。禁止、または計算から回避するとき、固定襲撃Actionは各残狼数仮説の内部で対象が非狼になる合法な襲撃に条件付ける。初期対称条件では対象選択は残狼数の重みを変えない。この操作は、位置を無条件に抽選してから「たまたま非狼だった」と観測するモデルとは異なる。後者なら7人例の6人生存夜盤面で非狼確率は1wが5/6、2wが4/6なので、全体一括条件付けでは1w=1/3、2w=2/3になる。本版はユーザー承認済みの指定合法襲撃を採用する。

許可＋包含時は対象が狼である可能性もChanceに含める。戦略変更は将来だけに反映し、過去の合法襲撃による条件付けを変更しない。

## 全候補と終局からの逆算

TreeNodeは全Action／Chanceを必要時に展開するビュー。枝を最大候補だけに絞らず、全対象を保持する。勝率評価は全ての終局結果から逆算し、各Action値の計算後に昼の村max／夜の狼max／random等重みを集約する。隠れ配置ごとの最適化はしない。

生存者が完全に交換可能なら、全対象の部分木は名前を置換すると同一になる。同時分布が各人数層の全位置集合に等重みであることを確認してから、同値な部分木を一度評価し全対象の値に使用する。非対称な同時分布では全対象を個別評価する。これは近似や枝打ちではなく、公開状態共有による厳密な終局評価。全履歴を独立のTreeオブジェクトとしてメモリに展開しない。

- 非対称3人の公開Boardでmax=3/5、random=1/3。隠れ配置を知った100%の選択に置き換えない。
- 5人・狼2人の村勝率は自噛み回避2/15、包含1/5。6人・狼2人は1/12と1/3、7人・狼2人は8/35と3/7、7人・狼3人は2/35と1/7。
- 9人：狼1〜4人×包含両設定の8条件で、初日から全将来の終局値を評価し、各手動Phaseで全対象値を再評価して終局まで実測。最終コードの実測は全履歴0.033720〜0.165204秒、Python追加割当ピーク最大62,736 bytes。詳細はv0.2-benchmark.json。生存者対称性により対象名を変えた全履歴の将来値は共有する。初夜だけの計測ではない。
