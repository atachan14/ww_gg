This stage builds on bedb17b, without changing production dispatch. `ExtensionForecast` has independent default-False medium, max and combined switches. It reuses the same complete canonical scalar/action key (public joint, private joint, acquisition/report/death/guard/attack records, physical Board, rules, configured strategy, target). It does not cache or transport policy vectors or choose a new CO/report rule. Existing labelled actor rankings, legal targets, tie multiplicities, physical masses and policy functions remain in the common solver. External private entry, opaque observer, trace, disabled memoization/renaming and hunters fall back. The retirement-proof optimization still excludes every medium/max case.

The scalar equivalence argument for each supported mapping is player-bijection equivariance of the complete input and configured symbolic rules. Equality never follows from player marginal colors alone. A canonical scalar can be shared before generation, but each original labelled target is still evaluated and its configured action policy still computes its score/tie distribution. Max is never moved outside expectation over an actor's information set. No simultaneous-max feature is invented; all comparisons preserve the existing engine's defined max behavior.
