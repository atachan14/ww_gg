## 方針と情報の範囲

`information_set_forecast.py` は公開の意思決定用信念と、実際の行動枝・観測者の条件付き確率を分けて持つ。

狼の情報集合は公開Board・公開取得分布・公開報告・初期狼全員のmask W。死亡済み仲間もWに残す。公開joint priorをWで条件付け、真の他役職・取得記録を分布として平均する。実世界の真占い師位置や新しい未公開結果を狼の選択へ渡さない。公開情報とWから論理的に確定する役職は、この条件付けにより利用できる。

randomはWで合法な生存対象を均等に選ぶ。maxは各合法対象の条件付き最終村勝率を平均してから最小化し、同値の最適対象を均等に選ぶ。世界ごとの最小化をしてから平均する先知的な方法にはしない。自噛みは既存のルールとinclude_self_bite設定を尊重する。

狼方針のcacheと評価は公開状態とWだけを使う。占い視点の本人・秘密結果・今回の強制占い先は観測者側の枝にだけ適用する。占い取得は夜の犠牲者確定前、公開は生き残った本人の朝。CO固定、なし/すべて、未訪問先優先、承認済み偽占いの均等則、霊能の設定は維持する。

## 公開信念をAのまま維持

実際の襲撃は各Wの方針π(target|公開情報,W)から生成する。村の公開信念は死体とルールに矛盾する候補を除き、終局/継続の枝で条件付ける。`dawn.observe` と同じく、πの選択尤度を掛けて推理するBにはしない。

生存狼1匹/2匹が半々、既知の非狼Player3を襲撃した例では、Aの公開信念は1/2ずつ。狼の均等選択確率1/5対1/4を推理に加えるBなら4/9対5/9になるが、Bの値を公開判断に使わない。実行枝の確率と公開意思決定用信念が異なるのは、この承認済み限定モデルの定義である。

村のmaxも、このAモデルの公開信念から将来の狼情報集合方針を評価する。観測者の秘密で村の候補評価や同値処理を変えない。ナッシュ均衡や別の秘密戦略は導入していない。

将来情報がなく公開の生存位置が交換可能な場合は、均等処刑とWで合法な襲撃の人数・狼数再帰で厳密に縮約する。特定位置の情報や占いCO・霊能がある場合はこの縮約を使わない。

## 数値回帰

- 最小3人生存の夜（狼2/真占い1、狼1/真占い3が半々、初日占いなし、CO反応なし）: 公開共通randomで生じた不合法未計算を解消。Wの合法randomを合成した襲撃確率はPlayer1=1/4、Player2=1/4、Player3=1/2。全枝が狼勝利で、真占い1の占い先比較は村0を返す。
- 実UIでも、4人・占いCO1・CO反応なし・初日Player3白・Player4処刑後に、真占い1の視点でPlayer2への占いが村0%／狼100%となることを確認した。以前の不合法未計算になる形を公開入力から作って検証した。
- 市民2・占い1・初期狼2、Player1/2が同じPlayer3白、Player1処刑後のD1夜、Player2占い視点、昼max/夜random: 占い先4/5は村5/6（83.33%）、狼1/6（16.67%）。旧共通指示モデルの7/8から変わる。旧モデルは4つの公開襲撃位置を均等化したが、Aは実際の狼ごとに3つの非仲間を均等化する。
- 同じ5人例の白対象Player3処刑は依然終局となり、比較画面を作らない。
- 7人の既存回帰: 公開狼数1/2匹不確定は村1/2、生存狼2匹確定は村1/3の比較表示を維持。
- 非対称な公開prior（狼2=3/5、狼3=3/10、狼4=1/10、真占い1、初日なし、Player5処刑後、昼max/夜random）: 占い先2/3は村5/6、占い先4は村23/30。非対称なpriorと本人・対象を置換して結果が一致する。

## 秘密漏洩の直接検証

7人・初期狼2・真占い2で、真占い1/2がCO済み。公開候補の狼は3/4または4/5で半々、Player7処刑後。W=3/4の狼方針は、占い師1/2への襲撃を各1/2とする。両者の候補評価は村7/10で同値。

新しい秘密の黒が占い師1にある実現と占い師2にある実現を入れ替えた試験でも、方針は各1/2のまま。各実現で村の実際の勝率は3/4。黒を持つ本人を知って選べば村1/2に下げられるが、それは狼が知らない秘密の利用なので行わない。

人工の相反する隠れ役職報酬表でも、同一Wの2仮説を平均した村1/2を比較し、2つの最適対象を各1/2にした。個々の実世界で村0になる方を選ぶ処理にしない。
