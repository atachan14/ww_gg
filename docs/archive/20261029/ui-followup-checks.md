# Board別設定・UI調整の確認

共同分布checkpoint `c692640`、後続要件記録 `f90dab7` からの独立したUI調整。

## 反映内容

表示オプションと陣営・役職別計算パネルをネイティブdetails/summaryで折りたたむ。情報欄は「現在勝率」「累積勝率」の短いラベルと、開いて読めるTipsへ整理。summaryはタップとEnter/Spaceで操作できる。再計算後も開閉状態を保持する。

最大勝率方針では村（昼）／狼（夜）の厳密Action値から同率最小PlayerIDを画面の初期対象にする。初期値は実配役や計算上の同率Action数を変えず、セッションの手動選択とは区別する。手動選択は再計算後も保持。ランダム方針には新しい初期選択を導入せず、未選択を維持する。

CO必須は「定員到達でCCO」「対抗が出たらCCO」を複数チェックできる。いずれか成立で必須、未選択は制約なし。両方選択すると後者が前者を包含する。旧単一条件入力も読み取り互換を残す。MAIN/TOP/独立比較ページで使用する。霊結果条件は追加しない。

各行動履歴には計算方針、COスナップショット、CO必須条件の集合を保存する。新Boardで変更しても過去Boardは変更されず、戻るとその時点の設定と対象を復元する。騙り可否変更のUIはまだないため、市民騙りを日ごとに変更する例は未実装。追加時には騙り設定も同じスナップショットへ保存する。

現在勝率の未来予測は現Boardで選んだ計算方針を仮定して評価する。未来のBoardで実際に変更された設定は、そのBoardの行動時から適用・保存する。未来に未指定の条件変更を予測しない。

## 検証

直接回帰65件合格。追加テストは最大値の同率低ID・既知狼の対象、ランダム未選択、手動選択保持、条件集合のOR解釈、入力拒否、過去条件の保全と戻る復元を検証する。既存の共同分布・Fraction・勝率回帰も合格。

実Edgeの独立headlessプロファイルでPC 1280px/mobile 390pxを確認。表示折りたたみのEnter操作、分数表示、再計算後の開閉状態、手動対象保持、複数CCOチェック、進行ボタン連打の一回処理、後続Boardで条件解除してから戻る際の設定復元、スマホ幅のTipsと横はみ出しを確認。

ランダム初期対象、霊結果条件、騙り設定変更UI、ギドラ、名称「戦略オプション」の確定は今回対象外。push・公開なし。
