# Root7 comparison and backend scope

The Edge validation in 3c35290 used an isolated browser as the UI client of the Python server on dedicated18801. Browser JavaScript submitted inputs and rendered server NDJSON frames. It did not execute the numerical solver in Pyodide, compare server/Pyodide engines, or test a numerical backend switch. No selectable Pyodide/browser-calculation wiring is present in this recovery copy's tracked app/static/templates. Untracked prior browser-engine artifacts are not evidence of an active backend. Server/browser calculation switching remains unimplemented/unverified here.

The current optimization affects Python server public fixed-CO evaluation in checked scopes, and exact existing-key construction for local root/one-hunter scopes through six original players. It does not automatically change a separate browser engine. A browser-context switch with the same cookie and a server execution-mode switch are tested UI/cache boundaries, not backend equivalence.

Full guard/attack histories and original wolf information are retained. See root7-history-results.json and root7_history_validation.py.
