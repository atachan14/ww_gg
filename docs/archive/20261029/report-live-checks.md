# 霊能申告の自動再計算復旧

基準HEAD `c15bf0c`。戦略UI②のイベント対象限定で `.report-select` が外れ、申告を変えただけでは再計算されない回帰があった。既存 `initializeLiveClaims` の対象へ追加する1行修正で復旧。CO・戦略変更と同じ直列送信／変更版番号／revision同期／古い応答破棄を利用する。霊能計算・手入力と未来報告の意味・保存・能力範囲は変更しない。

直接関連テスト27件合格（test_v04_input、test_strategy_ui、test_web）。JavaScript構文・git diff --check合格。

既存8771・実Edge PC1280×1000／mobile390×900で確認：夜は申告欄なし、翌朝は未入力、白→黒→未入力の自動再計算、未入力で元のFraction復元。黒で狼の霊騙りと確定するfixtureを再読込して保持し、次の処刑で決着後に戻ると保存申告と対象が復元。真霊fixtureの矛盾する黒入力で警告・進行禁止・旧確率非表示、白に修正すると復旧。mobileでも未入力／白を変更し、横はみ出しなし。

ブラウザのfetch応答を200ms遅らせて白→未入力→黒を連続変更し、送信が白と最新の黒へまとまり、古い白の応答で最新の黒が上書きされないことを確認。待機中の表示形式changeイベントと完了後の％切替も確認し、全確率の表示が選択形式と一致。待機中は通常操作の表示形式コントロールを既存仕様で無効化する（今回変更なし）。

確認画像は作業workspaceの `report-live-pc.png`、`report-live-mobile.png`。長時間の回線切断、別タブ競合、9人全履歴の負荷再測定は今回未実施。数値エンジンと未来分岐は変更していない。追加能力・部分開示・真結果騙り・黒X条件なし。8771のJavaScript応答へ反映済み、ローカルcheckpointのみ、push・公開なし。archive・別試作・独立ギャラリーは変更していない。
