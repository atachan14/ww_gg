## Why the earlier engine comparison had no rescue

The initial pure-six unit input has no future information and a completely exchangeable public wolf prior. `board_roles.prepare_evaluation` selects exchangeable reduction before constructing the evaluator (`board_roles.py`, `information_set_forecast.py:105–119`). It demonstrates correct key construction, not a need for that key in normal execution.

For ANY six-player colour partition with more than one block, the largest factorial product is5!·1!=120. A selected action target is itself a distinct colour (`exact_renaming.py:91`), and any death separates alive from dead; hence ordinary action keys or later surviving-player contexts already fall within120. The only possible720 case has all SIX colours equal and target=None. Most already-tested seer/medium fixtures have different CO groups and/or a directed published white recipient, so this cap is never their bottleneck. Root/hunter proof engines use their existing default10000 constructor, not this general120 cap (`root_secret_flow.py:169–185`); they are a different investigation.

The two cases above demonstrate that public scalar inputs with ALL six equal colours really can reach the120 decline. But proving a new key exists is still different from proving new useful value hits:

- The all-medium input already produces the original `party-scalar` descriptor and private reduced value key (`medium_value_key.py`; observed by the probe). In `solve`, these are tried after the complete key declines (`information_set_forecast.py:385–392`). Canonical rescue can duplicate an existing useful reduction.
- At six alive players this is the initial public scalar. Normal action targets and subsequent deaths already split a colour. The initial scalar is normally requested once per cold evaluator; a repeated identical request can already hit its labelled/reduced memo. We have not shown a material new reuse opportunity.
- The all-seer case avoids the medium reduction, but future acquisition can expand drastically: after executing a true seer, four remaining true seers may each choose five original targets, up to5^4=625 acquisition combinations per role world. This alone exceeds the prototype128-hypothesis admission. Root key rescue does not imply acceleration of that dominant future. The completed full future and all downstream support are NOT validated by this diagnostic.
