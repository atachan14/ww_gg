# 切り出し型：処刑後の群と正式法則を一夜へ引き継ぐ小試作

`CutOutDayNight` を独立追加した。4〜5人の正式Model A初期公開入力、狼1・狩0・均等行動から、Day1処刑→最初の夜の襲撃による死亡観測まで進む。初期CO配役を子状態で作り直さない。通常経路・公開・既定OFF・max・狩人・7人・全ゲーム勝率は対象外。

## 群・法則・質量の引継ぎ

初期法則は前段adapterの参照のまま。代表処刑の各勝敗/継続枝は既存の一手評価と `exact.action_outcomes` から作り、枝で条件付けた完全joint法則、正式な子Board、元のpastを保持する。群は親の各群を処刑対象の固定点部分群へ切り出すだけ。新しい初期prior、COグループ加重、独立な役職率の積を作らない。

処刑で終局ならそこで止まり、夜の取得・襲撃はしない。継続する子状態のrole質量がBoardと一致しない場合も補完せず停止する。

## 狼本人の最小設計

襲撃対象を公開法則から直接一様選択してはいけない。既存 `wolf_information_groups` で、受け継いだ法則を狼本人の初期狼位置と自身の攻撃履歴ごとの情報集合へ条件付ける。この範囲は初夜・狼1なので履歴は空、各本人群には同じ狼位置だけが入る。

`InformationSetForecast.wolf_policy` には**取得前の公開法則**と本人の狼位置を渡し、既存の均等・自襲撃なしの方針を取得する。別の占い師の秘密結果を条件に方針を選ばない。返った方針が合法な非狼生存者への厳密な均等分布と異なれば拒否し、勝手に均等化しない。

本人条件付き法則は物理枝の評価だけへ使う。各actorの元の群質量、設定済み行動確率、物理枝質量を掛けて、同じ公開死亡観測へ合算する。公開群と一時的な本人群は別物で、本人の位置を固定した細分化を公開群へ流用しない。

狼1・同じ生存人数・自襲撃なし・均等という今回の範囲では、ある対象が襲撃可能な各狼世界で選択確率の分母が同じ。公開の死体観測後の役職法則は既存 `public_children` の互換更新とも一致する。複数狼、max、GJ、自襲撃ありへ一般化していない。

## 夜の順序と切り出し保証

一時本人群では、処刑後の公開群から狼位置を固定して合法な襲撃対象を区分し、同じ群から代表一件を評価する。既存 `physical_actor_outcomes` を使用し、夜の占い取得は既存 `acquire_uniform` を通して襲撃前の生存者へ適用される。

処刑で取得者が死亡していれば次の取得はない。襲撃で取得者が死亡する場合は、その前の取得が残る。占い対象は元の全プレイヤーで、死体も既存ルールどおり候補に入る。現在夜の秘密取得を見て襲撃対象を変更しない。

既存の未訪問優先・均等取得と物理死亡規則は、保証済み群内の交換と可換。狼位置と処刑対象を固定する一時群では、代表と別対象の既知の交換で完全な枝を戻せる。全置換や生成元交換の安全性検証は行わない。公開死亡観測を合算した群は、処刑後の**公開群**から観測された襲撃対象を固定して得る。過去に分かれた公開群の再結合ではない。

`ChildState.stage` は `after_execution`、`before_publication`、`terminal` を明示する。夜の死亡後・Day2の新しい公開報告より前で停止する。翌朝の報告生成、CO変更、次の意思決定、本人Tableや未来cacheへの一般接続は行っていない。元の追跡者集合・roster・observed_prefixとpast順を保ち、潜伏真占の未追跡秘密を新たに補完しない。

## multiplicityとラベル

処刑対象群k人の選択質量はk/N。群の代表枝の質量はその選択に条件付けた値。`labelled_paths(result,target)` が返す個別処刑対象の枝質量は、その対象を選んだ条件で合計1になり、無条件の個人枝へは1/Nを掛ける。

各夜の `NightChoiceClass` は狼位置情報集合、元のactor質量、対象集合、multiplicity、条件付き選択質量を記録する。対象群k人なら選択質量はk/(夜の生存者数−1)。公開観測への合算では、個々の対象へ戻した質量を使うため枝の数や確率を落とさない。actor情報は内部の仮説集合の記録で、通常UIへ公開していない。

## 小検証と費用

新規4テストが0.919秒で成功。再現は `python -B -m benchmarks.player_match_groups.cut_out_day_night_fixture`、テスト subprocess は20秒上限。Morishiと競合する重い測定や全suiteは行っていない。

旧対照は、全処刑対象を `action_outcomes` → `project_private`、全本人情報集合の全襲撃対象を `wolf_policy` → `physical_actor_outcomes` で列挙し、共有・輸送なしに合算する。4/5人のCO例、占2不足CO、霊COの機会履歴も含め、全個人ラベルの確率・Board全体・完全秘密事後法則が一致した。公開役職法則は正式な夜の互換観測更新とも比較した。群内全置換の監査はテスト側だけで行う。

初期prior再構築・旧canonical照合・交換エンコーダを例外化しても進めることを確認。新経路の再配分・生成元検証・全置換検証は0。狼方針が取得前の公開法則から選ばれることもテストする。

市2霊1占1狼1、P1真占CO・P3白の例で、P4処刑後にP1が襲撃されても取得枠2の結果が残り、その中で死体P4を占う質量1/3を確認。P1を先に処刑した場合は取得枠1を保持し、枠2のP1結果を作らない。履歴時機はDay1昼の処刑、Day1夜の襲撃として保持する。

処刑のjoint走査・枝正規化、正式な子Boardテンプレート作成、群の切り出し、本人条件付け、方針取得、夜取得を含む物理カーネル、公開観測のjoint合算、ラベル輸送を別計時した。物理カーネル入力/出力仮説数、取得cache件数、輸送仮説数も記録する。夜の全ラベル観測を合算するための輸送費は評価時間に含み、任意の処刑ラベル全展開は別に記録する。

候補展開は実際に減ったが、完全法則の列挙・取得の秘密分岐・正規化・ラベル輸送は残る。小例の単発時間を総速度改善や実ゲームの保証とは扱わない。証拠は `cut-out-day-night-results.json` とローカル `.artifacts/cut-out-day-night-final.log`。
