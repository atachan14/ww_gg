# v0.4：霊能結果の手入力と将来開示

2026-10-07。v0.3のCO基盤と分ける次期案。計画の範囲は承認済み。夜間作業としてコード実装まで追加承認済み。実装結果は [v0.4仕様・検証](v0.4.md) に記録。以下は確認済みの方針と残る設計を分離した記録。

## 確認済みの方向

- 霊能CO者の結果欄は、本人の申告としてユーザーが入力する。真役職や真結果を画面へ自動入力しない。
- 真霊能の「結果騙り」は当面「認めない」だけのUI。狼の霊能騙りは虚偽申告可能。
- CO／結果と矛盾する候補を除外し、従来重みを正規化する。申告頻度モデルを新設しない。
- 将来方策の暫定既定は「結果：全て開示」。CO前の結果は対象外。翌朝に生存しているCO者が同時に報告する案をユーザー了承。
- 狼の霊能騙り報告方策は狼勝率max／random案をユーザー了承。「全て開示」条件では未発言を報告候補から除外。

## 計算と画面の分離

現在の未入力Boardには申告なしという入力事実だけを保持する。期待値計算の内部では、将来の開示機会を条件に従って一度だけ展開する。結果入力後、その機会を入力で条件付け、同じ処刑結果を再抽選・再生成しない。処刑対象、申告者、CO時点、公開予定時点を履歴で対応付ける。

真霊能の白黒は相関付き役職候補から導出する。狼の白黒は申告方策のActionであり、真結果のChanceとは分ける。公開情報に基づく方策を選び、隠れ真配役ごとの最適化をしてから平均しない。

同時報告の複数CO者は共同制約を評価する。各人の真率／白黒を独立に掛けない。公開内容の違うBoardは別々に評価し、確率加重する。全Treeの画面表示は不要。

将来の全開示offは、未発言候補とその選び方を確定してから追加する。最多確率枝や黒率50%判定を全結果の期待値の代用にしない。

## 実装で解決した詳細

- 同時報告Actionの単位と順序：公開情報で区別できない狼位置にも同じ方策を適用し、真結果の裏情報を狼方策へ渡さない設計。
- COした当日に入手した結果と、CO前の既往結果の区別。COや死亡の履歴と申告可能性を突き合わせる。
- 開示段階前に全枝終局した場合の停止。翌朝死亡しているCO者から結果を生成しない。
- 未来計算キャッシュは死者の役職と未開示結果の相関を保持する。v0.2の死者周辺化をそのまま流用しない。
- 受入値はv0.3の非対称盤面・合法襲撃の定義確定後、小人数から共同分布を独立照合する。

push、公開、archive変更、占い・護衛効果は追加しない。占い師・狩人の能力なし追加は別途承認済み。

将来maxの共同指示ベクトルとrandomの公開報告合算、CO時点からの報告機会、終局停止、相関保持キャッシュ、独立fixtureの検証はv0.4実装済み。ギドラ・CO必須の黒条件は未実装。
