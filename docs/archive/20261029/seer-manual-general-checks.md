# 手動占いの配役・CO一般化（公開前検証記録）

基準は公開版bd36faa。別worktree D:/CodexTemp/ww_gg-seer-manual-general-20261012。元の狩人研究ツリー・公開版・未来自動カーネルに混入させない。この検証時点ではcommit/push/deployなし。

人工的な5人/市民2/占い1/狼2・初日占い2CO・真占いCO必須のgateを削除。1～9人、各役職0～9、合計の範囲で試せる開発手動モデル。狼なし・初期狼多数は既存winner規則による初期終局として扱う。experimental_cast指定時だけ初期配役の狼少数条件を外し、通常モードの条件とBoard履歴整合validatorは保持。TOPの人数制限も同じモードへ合わせる。配役に存在しない役職へのCO、既存騙り/CCO条件と全て矛盾するCOは従来通り入力エラー。

占いは入力済み結果だけを完全結合役職の真報告に条件付ける。初日ランダム白の真の白対象抽選確率を保持し、偽報告尤度は明示選択された一定。偽報告発生方策や将来占い取得・私的利用・公開・未占い優先を生成しない。未来の行動/値は従来PUBLIC solverのmax/randomと終局累積台帳であり、一般の狼チーム私的情報均衡ではない。

霊能手入力も同じ結合役職と公開機会へ初期から条件付けし、過去訂正で一度消した世界を復活できる。霊能の未来報告は既存solverを継承。狩人は配役・COへ参加するが能力なしで護衛/GJ/護衛先最適化は計算しない。手動モードの各評価に250000仕事量の上限を設け、通常/霊能双方の公開solverへ適用。超過は勝率Pending、0%へ置換せず、失敗した戻り値をcacheへ保存しない。成功済みexact cacheの意味は維持し、requestごとの予算ContextVarは終了時復元。

人手COは現在以降で変更可能。過去actionのCO・方策は保存snapshotから復元し、過去報告者の資格を保つ。現在COを除いても保存済み過去の占い報告を別行で表示。同じBoardで結果を残したままCOを消す操作は資格不整合として拒否し、過去COイベントを復元したことにはしない。同日取得/公開の入力モデルを維持し、遅延公開は未対応。SystemLogへの拡張は別計画参照。

戻るでは占い/霊能の訂正済み証拠台帳を保持し、戻った日より未来の報告だけを落とす。cookie cold復元、死亡した報告者の過去データ、夜死亡した取得対象も検証。
