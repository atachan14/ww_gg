- images/board-overview.png：公開情報を入力する前の盤面
- images/sample-3-a.png：サンプル⓷-A（占いCO2人、村勝率25%）
- images/sample-3-b.png：サンプル⓷-B（占いCO1人、村勝率33.33%）

更新時は画面内の条件・数値がREADMEの説明に対応しているか確認してください。画像はユーザー提供のものを加工せず配置しています。
