# v0.3：霊能の人数・CO基盤（能力結果なし）

2026-10-07。ユーザー承認済みのv0.3を実装・検証。霊能結果の入力と将来報告枝はv0.4へ分け、今回のコードには含めない。

## 確定した追加要件

- TOPは村陣営／狼陣営の2列。村陣営に市民・霊能、狼陣営に狼を配置し、役職ごとの人数入力から合計を算出する。霊能は0〜1へ制限しない。合計9人上限と、狼数が村陣営人数より少ない開始条件を維持する。
- 現在の「役職」欄は「CO」へ変更する。COはユーザーの公開Board編集。真霊能を初日から自動COさせない。
- 騙れる役職は操作の禁止ではなく、本役職と申告役職が両立するかを計算する制約。市民・霊能は既定で役職騙りなし、狼は既定で全て。市民や霊能が自分の役職を申告することは役職騙りではない。
- 村陣営役職の「CO必須」に「対抗が埋まったらCCO」を既定とし、「対抗が出たらCCO」も選択できる。「なし」も比較対象として残す。霊能COが1人以上あるなら、生存する非霊能CO位置の真霊能を除外する。死亡者は新たにCCOせず、死亡前の制約は履歴で保持する。これは即CCOを選んだ場合の条件。既定の定員到達CCOは、その役職のCO人数が初期配役の定員以上になってから適用する。
- 「対抗が埋まったらCCO」はv0.3へ追加済み。霊能定員2でCO1人なら潜伏可、CO2人以上で非COの生存真霊候補を除外する。「対抗が出たらCCO」と「なし」も選択できる。
- COと計算条件に矛盾する候補を除外し、既存重みを正規化する。CO／発言頻度の尤度モデルは使わない。
- 陣営別・役職別の計算項目を、選択肢が一つでも表示する。村陣営の吊り先評価max/random、狼陣営の噛み先評価max/randomと自噛み包含、各役職の騙り制約・CO必須条件を整理する。ゲームルールが自噛み禁止なら「行わない」で変更不可。

## 実装の範囲

v0.3の霊能は村陣営の別役職として人数・位置確率・CO制約に参加するが、能力結果を勝率評価に使わない。未入力結果を自動生成せず、霊能能力の効果が含まれると誤解させない説明を表示する。霊能結果の入力・将来開示分岐はv0.4へ分離する。

「戦略」を「計算」と呼ぶ。max/randomは値の集約条件であり、表示上の対象を自動選択する操作にはしない。

## 状態・計算

初期配役、固定ルール、対象履歴、CO編集と各編集時の計算条件を正本とする。公開情報から市民／霊能／狼の位置集合を相関付きで導出する。真配役を一つ選ばない。

CO入力を真役職に直結せず、騙り可能性とCCO条件を合わせて適合候補を求める。情報に合わない入力は理由を示し、候補質量0を適当な確率や勝率へ置き換えない。編集案を修正可能な形で扱う。

CO制約が生む位置間の非対称性を保ち、各公開Actionの期待値を算出してからmax/randomを集約する。v0.2の人数だけの対称性最適化を無条件適用しない。

v0.3では現在までのCO・CCO制約を履歴ごとに適用し、後続の死亡でも保持する。計算条件変更は現在のBoardから先へ反映し、過去の制約を撤回しない。将来の自発COやCO頻度は生成しない。現在の制約で条件付けた後、能力結果も将来COもない後続評価は狼配置の周辺分布で厳密に計算できる。画面と手動履歴には霊能との相関を持つ同時分布を保持する。

## 手元QA後のCO即時更新改善

従来は「CO・計算条件を反映」ボタン、またはPhase進行のPOST時にだけCOを計算していた。CO・計算条件の変更イベントで既存の`/strategy`へ送信し、現在Phaseの確率・勝率を自動更新するよう修正した。Phase・行動履歴は進めず、指定対象を保持する。

再計算中と矛盾入力時は旧確率を「—」へ置き換え、進行を無効化する。矛盾したCO入力を画面に保持し、理由を表示する。修正すれば自動計算に復帰する。「再計算」ボタンでも再試行できる。通信は直列化し、途中の古い応答は描画せず、最新入力を更新済みrevisionで再送する。失敗時も旧数値を現在値として表示しない。

既存43テスト合格。内蔵実ブラウザで5人・市民3/霊能1/狼1を確認：1CO即時50%、2CO即時100%、3CO矛盾で入力保持・数値非表示・進行無効、2COへの修正で100%復帰、CCOなしの1COで66.67%。連続CO変更、対象Player4保持、Day1昼維持、表示切替、手動Phase進行と戻るを確認した。

## 定員到達CCOを既定に変更

手元QA後の明示依頼により、村陣営役職の既定を「対抗が埋まったらCCO」（`filled`）へ変更。TOP、新規ゲーム、未指定の計算条件に適用する。保存済みの明示条件は変更せず、MAINで切替可能。

定員は初期配役のその役職の人数。CO人数は死亡前のCOも含む公開欄を数え、CCOを新たに要求するのは生存者のみ。霊能2人の場合、1COでは潜伏を許し、2CO以上では生存する非霊COの真霊候補を除外する。即CCOは1COから同制約。「なし」はCCOによる除外をしない。役職騙りの可否と人数・相関制約は全条件で維持する。

市民3・霊能2・狼1の1COでは、申告者は霊能2/3・狼1/3、他の各位置は霊能4/15・狼2/15・市民3/5。即CCOなら同入力は矛盾。2COなら両申告者が真霊、3COなら各申告者が霊能2/3・狼1/3、4COは矛盾。定員1では即CCOと定員到達CCOの結果は同じ。

直接テスト45件合格。既存v0.2値を維持し、TOP既定、1CO/2CO/3CO/超過、条件切替、矛盾時の状態保全、選択対象とPhase履歴保持を検証。実ブラウザで霊能2の1CO、自動再計算、即CCOへの切替による矛盾と入力保持、既定への復帰、2COを確認。

上の受入表は、明記した「対抗が出たらCCO」を選んだ場合の参照例として保持する。9人計測JSONも計測時の明示条件を記録した過去の結果で、今回の新既定値への読み替えは行わない。
