# 画面と操作

根拠はコード(`app.py`、`templates/`、`static/`)と、ユーザーが確定した要件・名称。

## 2つの画面

- **TOP**: ゲーム中に変えないものを設定する。**GameCast**(配役)と **GameRule**(ルール)、戦略の初期値。確定すると MAIN の初日昼(Day1 昼)へ進む。
- **MAIN**: 日・昼夜(Phase)ごとに盤面を進めて確認する。
  - **BoardOverview**(盤面概要): 配役、日・Phase、陣営の勝率、決着。
  - **BoardPlayerTable**(プレイヤー表): 各人の番号・名前・生死・CO・能力結果、陣営と役職の確率、対象ごとの勝率、吊り先・襲撃先の選択。
  - **BoardStrategy**(共有戦略): その盤面の戦略の設定。
  - **GameTree**: ゲーム全体の分岐を整理して表示する(v0.6 で Preview・ローカルのみ)。
- 領域の親の名前は **Game** と **Board**(Session への改名は採用しない)。画面上の短い表示は「配役」「ルール」「戦略」。

## 進め方

1. TOP でゲームルールと戦略の初期値を決め、初日昼の MAIN へ進む。
2. 必要に応じて公開情報・戦略を変え、その条件の期待勝率を確認する。
3. 吊り先を指定して「夜に進む」。処刑後に決着する枝しかなければ、その場で決着画面になり、村と狼それぞれの勝率を表示する(勝者を一つに決めない)。決着しない枝があれば夜へ進む。
4. 夜は襲撃先などを指定して、次の昼へ進む。戻ることもできる。

## 入力中の計算

- 入力しながら計算する範囲を **Off / 役職率まで / すべて** から選べる(既定: 役職率まで)。「役職率まで」は、将来の勝率や行動の計算をせずに返す。
- 「更新」を押したときは、必ず全部を検証・採用・評価する。矛盾する入力は、有効な盤面として採用しない。保存の成功と、計算の失敗は別に扱う。
- 古い応答は捨てる(盤面の版・世代を照合する)。

## 表示

- 勝率は%が標準。表示オプションで分数に切り替えられる。
- 最大勝率の方針で、同率の候補がある場合、画面の初期選択は番号がいちばん小さい人。計算上は同率の候補を全部保持する。
- 補足は短いラベルと Tips(ホバー、スマホのタップ、キーボードで読める)。説明は Help > 操作 > 表示 にまとめる。
- Help ページに、サンプルケース(本棚)と技術ページがある。
