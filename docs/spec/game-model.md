# 配役・ルール・戦略

根拠はコード(`werewolf/exact.py` の `Rules`・`Strategy`・`ClaimPolicy` ほか)。

## 役職

| 内部名 | 表示 | 陣営 |
|---|---|---|
| `villager` | 市民 | 村 |
| `medium` | 霊能 | 村 |
| `seer` | 占い師 | 村 |
| `hunter` | 狩人 | 村 |
| `wolf` | 人狼 | 狼 |

- 人数は最大9人程度。狼は複数でもよい。霊能・占い師の人数も0〜1に限らない。
- 「COしていない」状態は `latent`(潜伏)。

## ゲームルール(TOP で確定し、ゲーム中は変えない)

| 項目 | 選択肢 |
|---|---|
| 自噛み(狼が狼を襲撃) | 許可 / 不許可(既定: 不許可) |
| 初日の占い | あり / ランダム白(既定) / なし |
| 連続護衛(狩人が同じ人を続けて守る) | 許可(既定) / 不許可 |

- 占い師は、対象が死亡していても結果を得る(死体を占う)。ただし、対象は夜の開始時点で生きていなければならない(2026-10-20 のユーザーの訂正)。取得した後に死んでも、取得済み・公開済みの結果は消えない。

## 共有する戦略(盤面ごとに変えられる)

| 項目 | 選択肢 |
|---|---|
| 昼の処刑 | max(村の勝率が最大の候補)/ random(候補から等確率) |
| 夜の襲撃 | max(狼の勝率が最大の候補)/ random |
| 自噛みを候補に含める | する / しない(ルールで許可されている場合だけ) |
| 偽の報告 | max / random |
| 結果の公開(共通) | 全部公開 / 公開しない。占い・霊能ごとに個別にも指定できる |
| 占い先 | 未占いの人から → 均等(今はこれだけ) |
| 偽占いの報告先 | 矛盾しない相手から → 均等 / 均等 |
| 護衛先 | 均等(今はこれだけ) |
| 勝ちが確定したら打ち切る | する / しない(処刑が max のときだけ。新しい設定の既定は「する」) |

## CO の条件(役職ごとの「COしなければならない」条件)

- 村陣営の各役職について、次の条件の組み合わせを指定する。どれか一つでも成立したら、その役職はCOしなければならない。
  - **定員到達(filled)**: その役職のCOが定員に達した(既定)
  - **対抗が出たら(counter)**: 同じ役職を名乗る人が出た
  - 条件なし
- 狼は「COしなければならない」条件を持たない。
- **騙れる役職**: 役職ごとに、偽って名乗ってよい役職を決める。既定では、狼は配役にいる役職を騙れる。村陣営は騙らない。
- 1人が複数の役職をCOすること(通称「ギドラ」)は未対応(将来案)。

## 盤面の更新と履歴

- 計算の設定は盤面(Board)ごとに保持する。新しい盤面の設定を変えても、過去の盤面の条件は書き換えない。過去の盤面に戻って編集し、先に進むと、その後の履歴は作り直す。
- 手動で公開情報を更新した枝は、元の戦略による期待値の重みには入らない(重み0)が、起こりうる証拠としては扱う。
