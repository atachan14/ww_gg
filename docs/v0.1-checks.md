## 完了した独立部分

- 昼の処刑候補を別々に評価する。処刑前の情報欄の一様平均、等確率処刑の表示、uniform必須入力・セッションを撤去した。
- 3人の未選択時の情報欄は「この3人例では、どの処刑対象でも同じ勝率」と明示し、対象指定後はその対象の評価と説明を表示する。
- 確率・勝率は％を標準とし、情報欄の右に％／分数の切替を設置した。表示は小数第2位まで、内部のFractionと正規化は維持する。
- 計算部分は3〜5人の各処刑対象の役職分岐を評価し、終局済み世界を絶対確率で保存する。未決着の条件付き分布と全体での未決着質量を分離した。
- 夜は各可能世界で合法な襲撃候補を列挙できるが、候補の確率・選択は付与していない。
- 9人・複数狼は初期配置と最初の処刑／合法夜候補までの限定実測を実施。9人UI・全履歴の評価・最適化は実装していない。

## 自動検証


**31テスト成功**（計算15・Web16）。新版repoに配置後も直接確認した。主な検証は以下。

- 3〜5人の全処刑対象について、役職配置・分岐確率・終局／未決着の質量が厳密に一致する。
- 非対称な入力分布でも、各候補の値を保持し、一様な候補平均に変換しない。
- 5人での初回処刑後、村勝ち1/5・未決着4/5を保ち、未決着枝内部の狼確率各1/4を区別する。
- 後続の分布を明示的に与えた場合、次の行動で既終局世界を再処刑せず、その確率を保存する。この検算用の分布を未確定の夜方策として採用していない。
- 各可能世界の夜候補は生存村人だけ。4人例の合法襲撃後は狼勝ち、5人例では未決着を確認。
- 不正・重複入力、実役職や旧uniform方策の注入、逐次再送信、戻る操作後の古い画面を確認。
- 初期画面が％で表示され、分数データは厳密値のまま、人数・配役は％にならないことを確認。
