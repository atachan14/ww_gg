### Mathematical construction rather than runtime certification

At an initial group-model snapshot, permutations inside equal claim classes preserve the generated initial assignment/history law. Fix every named endpoint in public ability reports. Q and P remain separate. Own observation conditions P while leaving public Q unchanged. Public compatibility/role-weight projection remains the existing Model-A updater; it is not replaced with a new Bayes rule. Reporting uses the existing complete-history public generation and private likelihood transfer. For wolf information cells I, actual mass is w_I=sum(P over I), and the configured target policy q_I(t) is calculated from public Q conditioned on wolf-owned I, never the viewer's secrets. Public role weights, world-internal history mixtures and physical branch/choice coefficients are not merged.

These construction reasons replace the old runtime group/owner comparisons in this route. Tests enumerate complete named output laws and each nontrivial group generator, including private observations. The live engine does not execute those comparisons.

### Existing equation and the three different measures

Start AFTER the common acquisition, owner-observation validation and physical/public continuation projection, at a pre-publication morning. Let h contain complete roles/acquisitions/guard/attack records, Q(h) be the current public joint law, and P(u) the separate normalized actual/viewer law. Write Qpi(z)=sum_{pi(h)=z} Q(h). This Q is the already established Model-A public continuation law, not a posterior obtained by replacing it with P or with a physical branch mass.

Let m be a complete medium-report vector. The existing uniform fake-medium instruction law and truthful medium reports define L_m(roles), with sum_m L_m(roles)=1. Its public probability and conditional history law are

\[
 q_m=\sum_h Q(h)L_m(roles_h),\qquad
 Q_m(h)=Q(h)L_m(roles_h)/q_m.
\]

These are the existing report_actions/random_report_outcomes and project_private operations: relative within-role acquisition histories survive the role projection. Only positive-q_m families are generated. No medium opportunities means one identity family.

Given Q_m, let f(h) be the living fake-seer claimant set, tau(h) the deterministic COMPLETE newly publishable truthful vector, and beta an approved fake plan. For zero fake claimants the plan is empty with probability1. More than one fake seer remains undefined. For one fake p, B_p(beta) is the current fake_backlog_options product law: every unpublished slot uses the same own PUBLIC past, original nonself target domain, unvisited-first fallback and uniform colors. This is not an invented sequential updating rule for unpublished fake slots.

For the configured noncontradictory/uniform policy, let T_p(Q_m) be the SET of distinct pending own report signatures in positive-Q_m hypotheses where p is true. If p has no possible true world, keep the full old noise law. Otherwise

\[
 A_p=B_p\cap T_p(Q_m),\qquad
 Z_p(Q_m)=\sum_{\beta\in A_p}B_p(\beta),\qquad
 F_p(\beta;Q_m)=B_p(\beta)1_{\beta\in A_p}/Z_p(Q_m).
\]

Here intersection means plan support, not multiplication of measures. Z=0 is the existing no_noncontradictory_fake_report refusal. \[
 \widetilde P_e(u)=P(u)\frac{q_e Q_e^\pi(\pi u)}{Q^\pi(\pi u)},\quad

### Exact contraction conditions

\[
 \sum_e p_e\sum_u P_e(u)g(u)
 =\sum_u P(u)g(u)\sum_e\frac{q_e Q_e^\pi(\pi u)}{Q^\pi(\pi u)}
 =\sum_u P(u)g(u).
\]

This is just exchanging two finite sums and cancelling the CURRENT normalizers. It does not claim Q_e or P_e are equal across observations. ### Formula and proof boundary

Let X include the full public history, Q, branch P, physical state and observer.
For the proposed report R, public exposure can establish
K(R=r|h,X)=k(r|X) on every positive-Q full hidden history h. This gives
Q_r(h)=Q(h) and P_r(h)=P(h) when the same channel applies to P and all support
checks succeed. It does NOT imply V(X,r) is independent of r.

The scalar is S(X)=sum_r k(r|X)V(X,r). Replacing the whole channel by one
continuation requires a sufficient retained state T: legal actions, configured
policy (including MAX tie distributions), physical payoffs and all future
information-conditioned transition kernels must factor through T, preserving
selected-owner records. For a shared target action vector it requires the
same values for every action, not merely equal maxima. Induction can then prove
V(X,r)=v(T(X)) for every supported r; only then does S(X)=v(T(X)).

Counterexamples in development tests distinguish what this claim does and does
not cover:

* An independent fair white/black public signal can select a history-configured
  wait/finish policy with payoffs0/1. Its expectation1/2 differs from retaining
  the white row0. This is a mathematical counterexample, not a new supported
  game policy.
* Public-history-dependent action scores(1,0) and(0,1) give E[max]=1 while
  max(E[scores])=1/2. Independence of the hidden prior does not remove history
  from the Bellman decision problem.
* The ACTUAL approved fake_uniform_options uses own previously reported targets.
  After initial fake2:black3, future options include target4; after publishing
  fake2:white4, target4 is excluded while unvisited targets remain. Both kernels
  are normalized and role-independent, but their future report distributions
  differ. Deleting or replacing that public record changes a real transition.
  This is a transition counterexample, not a demonstrated numerical difference
  for a correctly proved stronger quotient under the current fixed policies.
* An actual still-possibly-true seer report changes full Q and terminal MAX
  values across children. Its observations cannot be treated as known-fake noise.
* Missing the original declaration disables existing retirement validation;
  selected-owner input and nonterminal input are excluded from the experiment.

Thus the proposed simple nonterminal suppression fails its sufficient-history
contract. A more powerful quotient might sum successive noise channels while

### Formula and algorithm

The compiler already owns complete full-Q hypothesis groups I[f,t] for each fake
identity set f and true-report plan t, plus the configured fake plan chance C_f(u).
For each positive supported (f,t,u), join disjoint reporter plans to a literal
complete public event e. Accumulate

    J_Q(e,x) = sum_(f,t,u compatible with e) sum_(h in I[f,t],fiber(h)=x) Q(h) C_f(u)
    A_Q(e) = argmax_a sum_x J_Q(e,x) reward(x,a)
    M_Q(x) = sum_e J_Q(e,x) mean_(a in A_Q(e)) reward(x,a)
    V_P = sum_x (P(x)/Q(x)) M_Q(x)

All contributions to the SAME observable e are added BEFORE A_Q(e), including
contributions from different latent fake identities. Full target/color/acquired/
published-day plans remain in e; complete (roles,acquisitions) fibers retain
correlations. Existing common ratio/support checks apply P afterward. Q-positive
P-zero events still determine public decisions and are never removed by a viewer.
Nonnegative mass means only events with zero JOINT Q mass can disappear; no
positive event, hypothesis correlation or uniform MAX tie mass is altered.

The prototype traverses the compiler's indexed truth plans x positive fake
chances, accumulates event/fiber dictionaries, and uses the EXISTING common
optimal_targets/tie rule. It does not choose an action separately per hypothesis
or invent a case evaluator. It charges every component join and hypothesis term,
polls cancellation, and checks complete Q mass. Unlike the current streaming
Cartesian loop, it also retains all positive event rows while building moments;
no memory-saving claim is made.
