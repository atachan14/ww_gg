# v0.1：公開Boardから素村・狼1の3〜5人を評価する

2026-10-07の最新のユーザー訂正を基準とする。実装・QA中。9人・複数狼、特殊役職、CO・追加公開情報、Tree可視化、永続保存、外部公開は対象外。

## 用語と範囲

| 用語 | この版での意味 |
| --- | --- |
| Board | Day・Phase、生存者、公開された死亡履歴、公開条件からの人数制約を持つ盤面 |
| Action | 生存者の誰を処刑／襲撃した場合かという候補。全候補を保持する |
| Chance | 固定Actionの結果の可能性と厳密な条件付き確率 |
| Rule | TOPで確定するゲーム上の許可・禁止 |
| Strategy | 公開Boardで算出した候補別勝率をBoard値へ集約する方法 |
| 手動進行 | 指定対象のActionを条件に、終局済み確率を残して未決着Boardへ進む操作 |

初期配役は素村2・狼1、素村3・狼1、素村4・狼1の3通り。全員生存・役職未確定、初日昼から開始する。Wolfの位置や実役職をプレイヤーへ割り当てない。現在の版では、配置候補の位置列挙も使用しない。

非終局では狼がまだ1人いる。以前の死亡者が狼なら既に村勝ちだったはずなので、「継続する」という条件から以前の死亡者は非狼と推論できる。追加情報のない生存者は対称で、各人の狼確率は `1 / 生存者数`。この人数制約を使い、各人の確率を互いに独立とは扱わない。

この限定モデルを、情報差のある盤面や複数狼へそのまま一般化しない。例えば3人・狼1では各人の狼確率1/3でも、2人が同時に狼である確率は0である。

## 全Tree生成と終端からの評価

1. 各Boardの全Action候補と、そのChance結果を終局まで生成する。
2. 終局葉へ村勝ち1／狼勝ち0を与える。
3. 各Actionは子Boardの値をChance確率で重み付けし、対象別勝率を求める。
4. 昼の既定戦略は村勝率の最大、夜は狼勝率の最大をBoard値に採用する。
5. ランダム戦略は選択候補を等確率で加重する。実際の乱数は使用しない。

**最大同率の候補へ選択確率を付けない。** 最大値が同じならBoard値はその値で定まり、どの候補を選ぶかは別の操作。全Action枝は残す。手動進行には対象指定を使い、戦略から対象を自動選択しない。

最大化は公開Boardの対象別期待値を算出した後に行う。隠れた実配役を知っている場合の最適行動を求めてから平均する処理を行わない。例えば3人昼では各対象の村勝率は1/3であり、「各配役で狼位置を選ぶ」100%の評価に置き換えない。

Java参考資料のクラス名は [FaseBoard](../archive/wwExpected-java/src/main/java/model/FaseBoard.java)。対象ごとの役職別子Boardとその重み付けの意図は参考になるが、最大値を非終局Board全体へ集約する処理は見当たらず、完成した正解実装とは扱わない。[旧Pythonの同率案](../archive/python-legacy/docs/archive/v0.1/requirements.md) にある代表index選択も、この版では採用しない。

## 自噛みのRuleとStrategy

- TOPのゲームルールで自噛みの許可／不許可を確定する。初期値は不許可。
- 許可された場合だけ、戦略として自噛みの可能性を候補に含める／含めないを選べる。初期値は含めない。
- 不許可のRuleで「含める」は無効。UIで無効化し、改変された送信も拒否する。
- Ruleが不許可、またはStrategyで含めない場合、襲撃された位置は非狼という公開条件になる。固定襲撃Actionの結果は非狼死亡に条件付ける。
- 自噛みを許可して候補に含めた場合、この対称な基準例では対象の狼確率 `1 / 生存者数` と非狼確率をChance結果に用いる。

後者の確率は、この版の対称な公開盤面に対する計算条件。夜に狼の実位置を知った主体を作って選択させない。追加情報・複数狼・別の襲撃選択条件へ広げる際は、結果の尤度と条件付けを再検討する。

## 手動進行と確率の保持

昼・夜とも生存対象を1人指定して進む。固定したActionの全Chance結果を計算し、終局枝を止める。未決着枝があればそこへ進み、全枝終局なら両陣営の決着確率を表示する。実際の役職や結果を1つ選ぶ操作ではない。

この狼1の範囲では、固定Actionで継続するBoardは1つだけ。どの死亡者を表示するかはユーザーの対象指定から決まり、別の襲撃位置を自動で選ぶ必要はない。村勝ち／狼勝ちの既終局質量は、その後の操作でも内部に保持する。

## 表示の仮案

確率・勝率は％を標準とし、情報欄の右で％／分数を切り替える。内部はFractionを保持し、％だけ小数第2位に丸める。人数や日数は切替対象にせず、表示変更で盤面・選択をリセットしない。

情報欄の主表示は、**現在Boardへ継続して到達した条件での勝率**。全枝終局時は、直前Boardから指定Actionを行った条件での決着確率を主表示する。既終局枝を含む値は **「開始時点からの累積」** と明示して分ける。これは可逆な表示上の仮案であり、ユーザーの確認で調整する。

例えば自噛みなしの5人で最初の村処刑後、現在の夜Boardからの村勝率は1/3。開始条件からは既決着の1/5を残し、`1/5 + (4/5) × (1/3) = 7/15` となる。両者を同じ勝率として表示しない。

## 戦略変更・戻る操作と祖先の評価

- 現在Boardで戦略を変更すると、現在およびまだ手動指定していない将来の候補評価を再計算する。選択対象と公開盤面は保持する。
- 通過済みの指定対象と、その時点の戦略設定を履歴へ保存する。現在の変更で過去のChance確率を黙って変更しない。
- 開始条件からの累積は、保存済みの既決着質量と到達質量に、再計算した現在Boardの値を合わせて更新する。訪問した祖先に対応する条件付き評価へ後続の変更が伝播する。
- 「前のBoardに戻る」は直前の指定を取り外し、その時点の戦略と対象選択を復元する。後続の進行は破棄する。過去の対象を変更して進む場合、そこから先を新しい条件で作り直す。
- 同じBoardでも戦略条件が異なれば値が変わり得る。盤面だけで結果を使い回さない。
