# Bounded complete-key planning prototype

Comparison-only implementation: `benchmarks/player_match_groups/bounded_key_plan.py`. No app factory imports it; current <=6 / limited-seven admission and default OFF are unchanged. Numerical source remains c97f630. This is a key-construction experiment, not an enabled new evaluator or a completed general-seven rollout.

The adapter derives the current canonical constructor with explicit single-occurrence source guards, preserving its complete snapshot and equality checks. A future constructor edit makes the adapter refuse import until revalidated. Only the cap location changes: original colour factorial count no longer rejects first; the existing full-snapshot leader-swap proofs run within a local plan, then the ORIGINAL mapping limit is applied to the product of unproved block factorials. A proved full symmetric block needs only its one original order. Proofs include public/private joint hypotheses and exact masses, acquisition/attack/guard histories, public relations/rosters, physical Board, observer, rules/strategy, wolf policy contexts and verifying actor mask. Display PlayerData is never read, synthesized or rewritten.

Default admission is intentionally limited to original counts <=6, each law <=128 hypotheses, <=32 rosters/records per ledger, <=8 profile contexts and <=16 policy rows per context. Conservative source-cell accounting covers observer and physical/context Boards as well as both joint laws:4096 source cells,32768 cumulatively serialized cells,16 snapshots,8 attempted swaps and0.05s cooperative local deadline. These are bounded work proxies, not an exact byte meter or an OS preemptive timeout. Checks occur before each bounded snapshot/swap and preflight; individual serialization is input-size bounded. The prototype retains no cross-call key/value cache. A plan is single-use, including after interruption. Its telemetry reports counts and block sizes, not identities or secret contents.

Local cell/snapshot/swap/time exhaustion produces None, permitting an explicitly integrated caller to continue the unchanged original evaluation. The prototype itself does not choose any policy or install a fallback evaluator. Request-owned tick/cancellation exceptions propagate; a spent request budget is never reset or silently converted into a reusable value. Unsupported observers/shapes produce no key. Only a completed key is returned.
