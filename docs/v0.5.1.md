# v0.5.1：内部処理の共通化・回帰テスト強化

公開v0.5 `277f37a` を基準に、検証済みの `e41b999` / `fe4bd0b` を含める
保守更新。ユーザーの公開承認に基づき既存master/Vercel ww-ggへ反映する。
実装基準は `fe4bd0be30f2c5c5c78fd61c6545031542a9e0b4`。
公開URLは https://ww-gg.vercel.app/ 。

## 変更

- 偽霊能報告の公開評価と旧狼本人評価の同率max選択を、既存の
  `optimal_targets` / `uniform_policy` へ接続。
- 旧本人評価器の公開順位による対象選択も同じ `optimal_targets` を使用。
  合法候補を絞る順序、全同率候補、random、本人の均等平均は維持。
- 異なる報告指示の公開事後と枝質量、公開/本人情報分離、Pendingを守る
  専用回帰を追加。[第1単位](max-commonization-step1.md)・
  [第2単位](max-commonization-step2.md)に詳細を記録。
- アプリ版数、Header、CLI、README、技術HELPの公開基準参照を0.5.1へ更新。

UI操作・API入出力・計算仕様/値・保存形式は変更しない（版数表示のみ更新）。
候補数・探索・再帰・cacheの計算量削減は行っていない。速度の比較計測もなく、
速度向上・軽量化は主張しない。戦略タグ、真偽基準、COグループ、入力受理、
新しい相互max/占いmax/護衛maxの仕様は追加しない。

## 検証

実装基準で全635テスト318.036秒成功。第1単位は公開v0.5と全候補値が一致、
第2単位は直前の実コードと昼夜4設定/observer2入力の全値・全traceが一致。
最終版数差分はHELP/公開構成と関連回帰48テストで検証し、6.531秒で成功。
実装基準から計算処理・保存形式・静的資産の追加変更がないことも確認。公開ブランチSHAとVercel
Production Source SHA、公開版数・代表計算・保存再読込・HELPを別々に照合する。
実施証跡はローカル `.artifacts/integration-validation/v051-*` と作業結果に記録。

既存認証・本番設定・署名キーを維持し、保存形式VERSIONは変更しない。
