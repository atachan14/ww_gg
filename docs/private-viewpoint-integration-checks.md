## 対応した範囲

- 夜のBoardTable下に全体・占い・狩人・狼の閲覧視点を表示する。配役にない役は表示しない。昼には視点ボタンを表示しない。夜の公開BoardLog非表示は引継ぎの動作を維持する。
- 行全体のクリック／Enterで人数を選ぶ。公開候補で成立する組合せだけを許可し、狼は死亡済み仲間を含む初期狼全員を選ぶ。
- 視点中は公開入力・進行をロックし、全体で復元する。同じ役ボタンは再選択となる。キャンセルと古い応答の排除を維持する。
- 占い師の秘密欄は公開CO詳細と別の行に追加する。潜伏中もDay1から入力可能（初日占いなしではDay1枠なし）。同役COの公開結果は初回だけコピーする。その後は別ストアで編集し、空欄を白で埋めない。
- 秘密はsessionStorageのBoard・本人・役キーで保持し、同Boardの公開revision更新で消さない。別Boardには自動継承しない。取得日の枠と公開COデータを混同しない。
- 真の秘密情報で役職確率を絞る。不整合時は確率を消して不整合表示にし、秘密欄は修正可能なまま残す。
- 狼視点の合法な襲撃先について、次の朝までに決着する村／狼の勝利確率だけを既存の即時遷移で計算する。0% / 0% は次の朝に未決着であることを表す。
- 再計算中に確率要素がなくても列幅計算が例外を出さないよう修正した。

## 情報隔離と未対応

`/private-view` は公開状態からreplayしたBoardを私的表示アダプターへ渡すだけで、秘密を公開CO、公開ログ、game session、公開forecastへ書き込まない。公開の方針選択・同率処理を変更しない。

私的条件付きBoardを既存の最終勝率評価器へ渡してはいない。全視点の最終能力勝率、占い先の取得／将来公開を含む情報価値、狩人の護衛能力・秘密護衛履歴は未対応と明記する。BoardOverviewとCOグループ内訳は公開情報の表示である。これは私的期待勝率評価器全体の完成ではない。
