# v0.7・v0.8 の範囲(案)

v1 に広げられる基盤を、v0.7・v0.8 で作る(2026-11-01 の方針。基盤と保留の一覧は [calculation.md](calculation.md) の「5. 基盤と保留」)。進め方は、2026-10-30 の全体レビュー([../design-review-20261030.md](../design-review-20261030.md))で勧めた「芯の試作 → 答え合わせ → 範囲を広げる → 画面を切り替える」に合わせる。2026-11-02 にユーザーと決めた。

## v0.7: 計算の芯の試作(画面はまだつながない)

目的は、新しい定義どおりに計算できることと、9人まで伸ばせる見込みがあるかを確かめること。

- **入口**: Board(公開情報と戦略)を渡すと、役職率・勝率・行動ごとの勝率を返す関数。どの Board も単独で計算できる([tree.md](tree.md))ので、Tree はまだ要らない。
- **配役**: 市民・占い師・霊能・人狼。狂人なし(PP・RPP は起こらない)。
- **ルール**: 自噛み、初日の占い。
- **戦略**([calculation.md](calculation.md) の「3. 戦略」)
  - CO可能性: 狼陣営はすべて、村陣営はなし。
  - 約束: CO は「対抗飽和直後 | 黒取得直後」。結果開示は「黒取得直後に黒対象と黒結果」。
  - 想定: 結果開示は「取得直後にすべて」。占い位置と偽の報告の仕方は、順序付きの絞り込み(偽の報告は「破綻しない報告 > 均等化」)。
  - 噛み位置は、狼の勝率の最大化。処刑の後に決めるので、順番に解くだけで、均衡は要らない。
  - 処刑は、公開盤面での村の勝率の最大化。同率は等確率。
  - 偽の報告の最大化(今の版の max)は捨てる。暫定の措置だった(ユーザー 2026-11-02)。
- **表し方**: 同じ立場の人を名前で区別せずに人数で数える形(一致グループ)を、最初から土台にする。
- **答え合わせ**
  - 開発用のテストで、配役の候補を全部数える独立の計算と照合する。
  - 定義が変わっていないケースは、今のコードとも照合する。例: 5人村の例(市民4・人狼1)の 7/15。
- **計測**: [../PERFORMANCE.md](../PERFORMANCE.md) の7人のケースを、新しい定義と上の戦略で計る。今の 89/224 とは値が変わるので、正解は独立の計算で出す。

## v0.7 の後半か v0.8: 狩人

v0.7 の最初の計測が済んでから足す。平和な朝、連続護衛のルール、連ガなしで前の夜の護衛先が効くことなどを扱う。護衛位置は順序付きの絞り込み(最大化なし)。
