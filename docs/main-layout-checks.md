# MAIN配置の反映・確認

基準HEAD `8ffef95`。ユーザーがUI5案を見て確定した大枠を、v0.4のMAINへ反映した。計算・状態管理・APIは変更しない。

## 確定配置

最上段は各Board共通のゲーム情報行。配役とルールを開いて確認でき、％／分数の表示切替は常時操作できる。ルールはTOPで確定済みの読み取り表示で、MAINから変更しない。

その下は左の1行目にPhase・生存人数・現在勝率・累積勝率とaccessible Tips、左の2行目に広いプレイヤーテーブル。右の既存戦略パネルは2行にまたがる。v0.4の陣営・役職アコーディオン、CO必須集合、偽霊能報告方策等はそのまま維持する。

役職内訳は初期表示。村陣営の見出しボタンから市民・霊能・能力なし占い師／狩人の列を開閉する。矢印・aria-expanded・aria-controlsを付け、Enter/Spaceで操作できる。再計算後も開閉状態と既存の手動対象・設定を保持する。内訳のない配役では開閉ボタンを出さない。

スマホは概要→テーブル→戦略の縦配置。表の幅を圧縮せず、表内で横スクロールする。霊能申告・COグループ内訳は既存機能を残してBoard配置の下に表示する。その下のTreeは未実装表示の場所だけで、Tree描画・追加探索は実装しない。

## 確認

関連Webテスト19件合格（test_web、test_followup_ui、MediumWebTests）。全数学suiteの再負荷は行わず、計算コードは変更していない。

実Edgeの隔離headlessプロファイルで9人C3/M2/S1/H1/W2を確認。PC 1600×1100で戦略の2行spanとテーブル幅、スマホ390×1000で縦配置・表内スクロール・戦略展開時の縦長さを画像確認した。

内訳初期表示、Enterによる開閉とaria、CO編集時の開閉・手動対象・配役表示の保持、分数表示、進行→戻る後のFraction一致を確認。ゲームルール編集入力は追加していない。
