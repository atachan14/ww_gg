## Item IV design, distinct from item VI implementation

Item IV design is complete in [simultaneous-action-design.md](simultaneous-action-design.md), preserving existing uniform ties and Pending. This does not implement item VI or make every item-I case numeric. Its contracts are stage-start information sets, collecting all intents before shared physical resolution, the joint law of simultaneous choices, best-response conditions, and explicit unique/multiple/no-admissible/undefined/unproved outcomes. Existing uniform ties and fixed configured continuation policies are the default contract. IV is a bounded design/review effort; VI's general solver and integration are substantially heavier. No measured completion time is available.

An arbitrary joint law is not determined by marginal policies, and general mixed Nash probabilities can conflict with the existing uniform-best-ties rule. These are decisions for a concrete requested extension, not a reason to silently change current behavior. Zero-support observations fall under the EXISTING agreed "想定外" concept. An actual observed input with no compatible worlds is an unexpected input Board; a hypothetical comparison branch with zero support is an unexpected comparison branch, whose missing value prevents certification of the original strategy but does not prove the original input Board inconsistent. Existing refusal/Pending handling needs no new model decision. Only a future request to assign a normal number to that unexpected branch would require a belief/observation rule. Item-I completion must not be expanded to require such a new rule. No extra model decision is necessary to complete IV or prepare a clearly bounded release candidate. Releasing that subset while item I remains incomplete still requires the user to approve changing the release condition. User judgment is needed if v0.5 must cover those currently undefined cases numerically or must adopt a different equilibrium/tie/correlation rule.
