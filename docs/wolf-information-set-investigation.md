# 狼情報集合による襲撃方針の調査（2026-10-13）

## 結論

`seer_view_public_instruction_private_illegal` は秘密結果の矛盾とは限らない。現行の公開共通襲撃指示は、その位置が非狼である候補が各生存狼数に少なくとも1つあれば合法とする。その共通指示が、観測者の条件付き分布では必ず狼を狙うことがあり、実行できず未計算となる。

狼は自身と仲間の組合せを知る。襲撃候補はその組合せWで決める必要がある。真占い師の実位置や新しい私的取得結果まで実世界ごとに見て選ぶことは別であり、それは情報漏洩になる。

既存のmax/randomと同値均等化を、Wの情報集合に適用する方式は表現可能。既存の遷移・取得・報告生成・公開/私的二分布を再利用できる。ただし現在の公開スカラーsolverをWで絞って呼ぶだけでは、後続の村がWを知ってしまうため使えない。Wで合法候補を絞るだけの近道も、Wの条件付き期待値を最大化した方針とは異なる。

## 最小反例の全条件

初期4人、市民2・占い1・狼1。初日占いなし、自噛みなし、CO反応条件はseer=none（潜伏の真占い師が強制CCOしない）。Player1だけ占いCO、他は潜伏。公開候補は次の2つが半々。公開結果・秘密過去結果なし。

| 候補 | 初期狼 | 真占い師 | Player1のCO |
|---|---|---|---|
| A | Player2 | Player1 | 真 |
| B | Player1 | Player3 | 狼の偽CO |

Player4をD1昼に処刑して3人生存の夜へ進む。夜random、すべて開示。

現行 `legal_targets(public)` はPlayer1・2・3を返し、共通random指示は各1/3。真占いPlayer1の視点では候補Aだけとなり、Player2は必ず狼。この指示を実行しようとすると未計算になる。

Wごとの合法randomなら、Aの狼Player2はPlayer1・3へ各1/2、Bの狼Player1はPlayer2・3へ各1/2。全体の襲撃確率はPlayer1=1/4、Player2=1/4、Player3=1/2。どの実行も合法で、非狼を1人減らすと2人生存・狼1で即座に狼勝利。よってこの反例の最終村勝率は0であり、未計算にする必要のないrandomケースである。

3人生存は、1狼の夜が未決着で成立する最小人数。2人生存は既に終局となる。

## 現行コードが表現していること

- `exact.legal_targets`（418行付近）: 公開の狼数ごとの非狼候補の存在条件。実世界ごとに仲間を除いた行動分布ではない。
- `exact.action_outcomes`（430行付近）: 対象を指定した介入の遷移。対象が狼の候補を除き、各狼数のpriorを保つよう正規化する。狼の選択確率は含まない。
- `seer_future_forecast.solve`: 公開Boardに対するmax/random。狼情報集合Wごとの最適化はない。
- `wolf_view_forecast.solve`: 選択した狼視点のWで仲間を除く処理は既にあるが、順位は共通の公開スコア。全Wの方針を構成して公開の襲撃分布へ統合する処理はない。
- `wolf_view_forecast.private_solve/private_action`: 観測者に条件付けた独立分布と正規化を持つが、指示自体は公開共通のまま。観測者が真占い師のとき、これを狼の情報集合として使うことはできない。
- `Hypothesis.roles[0]`: 初期狼全員のmaskが残るため、死亡した仲間を含むWでグループ化できる。真の他役職と取得記録はjoint分布で保持されている。
- `seer_fake_uniform`: 承認済みの偽占い候補・色の均等則は公開情報だけを使い、仲間や私的取得結果を見ない。今回の改善でもこれを変更しない。
- `dawn.observe`: 観測死体は非狼条件で互換性を更新し、狼の選択戦略による追加尤度は使わないと明記されている。

## 最小の実装方向（未実装）

1. 狼方針の情報集合キーを、公開履歴・公開報告・現在のルール/戦略・初期狼mask Wで作る。観測者の秘密欄、真占い師mask、新しい未公開取得結果、個々の実世界識別子をキーや選択条件へ入れない。
2. public joint priorをWで条件付け、W以外の役職・取得履歴を分布として保持する。公開から論理的に推論できる他役職は利用可能だが、選ばれた実世界の他役職を直接読むことはしない。
3. Wで合法な生存対象に対して、既存の設定を適用する。randomは均等。maxは同じ情報集合内の条件付き期待値を比較し、同値の最適対象を均等化する。昼の村判断は引き続き公開信念だけで行う。
4. 同一Wの全仮説へ同じ方針π(target|公開情報,W)を適用する。πは公開joint priorから決め、占い先比較の私的介入targetで変えない。
5. 全Wの実際の行動枝を確率付きで集め、公開に見える死体・結果ごとにまとめる。終局と私的期待値は実際の配役の枝で集計する。

合法性、random、同値処理、取得、偽報告は既存部品で再利用可能。情報集合に基づく夜の方針生成と、公開信念の更新方針を結ぶ部分が新規となる。ナッシュ均衡の実装は必要条件としていない。

## ユーザー判断が必要な更新方針

**A. 既存の観測互換方式を維持する（最小変更の候補）**

狼はWで合法な行動を選ぶが、村側の公開信念は現在の死体互換性・公開報告更新を維持し、狼の選択確率自体からは推理しない。実際の行動分布・勝敗集計と、村が意思決定に使う公開信念を分ける。Wのmax評価はこの既存の村方針を前提にする。現行の観測モデルを保ちながら、まずrandomと合法性から実装可能。

**B. 狼の選択確率も公開推理に含める（仕様追加）**

公開posteriorを、事前の配役/取得分布×π(target|W)で更新する。選択戦略そのものが情報を与える。maxでは現在の選択と、その選択を見た村の推理・将来行動が関係するため、候補評価時と実選択時の信念、未選択の枝の扱いを追加で定める必要がある。単に旧solverの呼び出し先を変更するだけでは済まない。

この差は数値で確認した。6人生存で、生存狼1匹（初期狼Player1・7）と2匹（初期狼Player1・2）が半々、Player3は両候補で非狼。Wごとの均等襲撃ではPlayer3を選ぶ確率がそれぞれ1/5と1/4。Player3襲撃の選択尤度を推理に使うBなら、公開狼数は1匹4/9・2匹5/9。現行の指定襲撃遷移と互換観測では1/2ずつを保つ。したがってBは既存モデルの数値を変える仕様であり、黙って導入しない。

公開スコアの順位をWの合法候補でフィルターするだけの暫定修正は、現在の狼視点の考え方を流用できる。ただしこれは「公開順位を守る」方針であり、W情報集合の期待勝率maxを実装したことにはならない。

## 回帰テスト案と今回の実測

`tests/test_wolf_information_set_characterization.py` の3テストが成功。計算本体の修正前の特性記録として、現在の未計算、Wランダム参照分布1/4・1/4・1/2、全枝合法・終局、隠れた真占い師の割当を変えても同じWのrandom分布が不変、選択尤度あり/なしの4/9対1/2を再現した。テスト内の参照カーネルのみであり製品には接続していない。

実装後に追加すべき回帰:

- 最小反例がPendingでなく0の村勝率を返し、Wごとの味方襲撃確率が0になる。
- 同じ公開情報・Wの中で、真占い師や未公開取得結果の実現値を替えても方針πが変わらない。公開joint prior自体を変える試験とは区別する。
- 2人の真占い師のどちらが秘密の黒を持つかだけが違う仮説を同一Wで平均してからmaxを取る。実世界ごとに黒を持つ本人を噛む先知的なmaxにならない。
- maxの同値対象を均等化し、プレイヤー置換で方針・能力先比較が変わらない。
- 死亡済み仲間を含む初期W、自噛み許可/禁止、初期/生存狼数、終局枝を検証する。
- 公開信念は選んだA/B仕様の数値になる。観測者や秘密入力を変えても同じ公開履歴で村の方針が変わらない。
- 現在の指定5人・同じ白の占いCO2人、7人・狼数不確定、偽占い則と取得日/公開日を維持する。
