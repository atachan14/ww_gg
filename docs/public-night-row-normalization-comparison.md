# 旧公開夜行の合法条件付けと一括条件付け案の比較

2026-10-13、基準0fad272。現行コードの読取りと数値確認。夜の全体行定義を変更/採用せず、フラグ・本人視点・Overviewの表示も変更しない。

## 既存仕様として確定した部分

exact.legal_targetsは、自己噛みを含めない場合、対象が非狼となる配役が**すべての生存狼数区分に存在すること**を要求する。exact.action_outcomesは対象が狼のworldを除外する。その後、元のworld重みqを P(w) / Z(w) 倍する。P(w)はその狼数の事前質量、Z(w)はその狼数で対象が非狼となる質量。狼数の区分ごとに条件付けるので、狼数の事前割合は変わらない。

自己噛みをStrategyに含める場合はwolf worldも除外せず、その正規化も行わない（Rulesが許可していることが前提）。本人や襲撃フラグは、この仮想行計算の入力ではない。

根拠はexact.py:legal_targets/action_outcomesのコメントと式。tests/test_wolf_information_set_characterization.pyは指定行動が狼数priorを保つことを固定し、test_seer_multiple_wolves.pyにも旧方式のcount保存/実行不能の回帰がある。

合法配役全体で一括正規化する案は、q / Z、Z=sum_w Z(w)。対象が非狼という条件により、狼数の混合割合も変わる。旧方式と同じとは扱えない。単一の生存狼数なら P(w)=1なので両式は一致する。

## 通常開始から到達する6人の例

6人・初期狼2・他は村人、全配置均等。P6を昼に処刑した夜、P1〜P5生存。昼/夜random、自己噛み除外。現在1wが1/3、2wが2/3。P3の仮想襲撃行を比較する。

初期15配置は各1/15。P3が狼の5配置を除外し、合法配置は10個。

| 狼数 | 事前質量P(w) | 合法質量Z(w) | 旧の合法各world重み | 一括案の各world重み |
|---|---|---|---|---|
| 1w | 5/15=1/3 | 4/15 | (1/15)×(5/4)=1/12 | (1/15)/(10/15)=1/10 |
| 2w | 10/15=2/3 | 6/15 | (1/15)×(5/3)=1/9 | 1/10 |

旧の条件後割合は1w=1/3、2w=2/3。一括案は1w=2/5、2w=3/5。

P3襲撃後、2wは4人生存で即狼勝利。1wは4人の昼へ継続し、村最終勝率1/4。

| 値 | 旧行 | 一括条件付け＋A後続の案 |
|---|---|---|
| 村期待勝率 | (1/3)×(1/4)=1/12（8.33%） | (2/5)×(1/4)=1/10（10%） |
| 狼期待勝率 | 11/12 | 9/10 |
| 朝まで村勝利質量 | 0 | 0 |
| 朝まで狼勝利質量 | 2/3 | 3/5 |

AのOverview（自然な仲間別random襲撃）は1/12。この例で一括案の行を単純平均してOverviewにしてはならない。行の仮想指定の条件付き母集団と、実際の仲間別行動方針の母集団が異なるため。フラグを付けて変わった数字ではない。

## 行が新しく出る場合もある

6人・初期狼2で、初期W={1,6},{3,6},{1,2},{2,4}が各1/4という合法な固定priorを作りP6を処刑する。P2は2w区分では必ず狼なので、旧legal_targetsにはなく行は—。一括案はP2非狼の1w区分だけを残せるため、村1/4を出せる。この変更は表示対象範囲にも影響する。

5人・狼1の単一狼数例は、合法質量4/5で両方式とも対象を除く4worldに各1/4、村期待勝率1/4。通常の単一狼数画面だけでは差が見えない。

## 統合前の判断

旧も合法配役を除外していたが、**狼数別**という条件が重要。既存行の意味と区分割合を維持するなら、その初期の条件付けを明示的な仮想対象方針として残し、後続の行動/情報処理だけAへ移す方法がある。旧solverへの隠れfallbackは不要で、同じA engineへ異なる初期measureを渡せる。

一括案を採用するなら、上述の分母・数値・行の出現範囲の変更を承認してから行う。モデルAへの統合そのものが一括条件付けを強制するわけではない。今回の確認を理由に無断で切替しない。自然にその対象を選ぶイベントとの二択UIを新設する必要はない。
