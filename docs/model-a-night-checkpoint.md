# モデルA夜行・評価状態圧縮のローカル検証

夜の対象固定行は、生存狼数ごとに合法世界へ条件付けし、狼数の事前比率を維持する。合法世界がない狼数群を含む対象は従来どおり非表示。全世界を一括で条件付けする案は採用しない。後続行動は公開情報と狼本人の情報集合で選び、閲覧者の秘密を公開方針へ渡さない。

評価専用の圧縮は、現在の固定COモデルで将来に影響しない潜伏役の区別を除く。元の公開Board、役職確率、入力、履歴は変更しない。生存占いCOの公開取得がある場合は適用しない。霊媒のスカラー値キャッシュは公開の狼情報集合・真霊媒との相関・未公開処刑対象の真偽を保持する。対称な対象でも行IDと同率選択人数は維持する。狩人能力が将来実装される際には適用条件を再審査する。

Windows Python 3.12で全体419テスト成功、74.174秒。追加の5人全員霊媒COケースを含む圧縮対非圧縮モデルAの比較2テストも成功、5.796秒。random/max偽報告で最終値・対象行・今日中の値が一致する。

代表ケースの実測：9人（狼2・霊媒2・占い1・狩人1、霊媒CO2人、他潜伏）約3.8秒。9人全員霊媒COは狼1/霊媒8で0.594秒、狼2/霊媒7で5.484秒。既定250000 work・20秒以内の測定であり、一般性能保証ではない。予算超過はPendingとし、旧評価器へフォールバックしない。
