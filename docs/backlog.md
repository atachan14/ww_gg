# 後続設計・UIバックログ

共同分布・勝率接続のcheckpointは `c692640`。今回の追加事項はここへ記録し、共同分布の実装へ混ぜない。

## 確定した履歴設計

計算設定はBoardごとに保持する。例：1日目は市民騙りを許可し、2日目から禁止する。新Boardの設定変更によって過去Boardの制約・行動条件を書き換えない。戻ったBoardを編集して進む場合は、その後の履歴を作り直す。

現在は各行動履歴に `policy`・`claims`・`claim_policy` のコピーを保存し、再生時に各時点の設定を使う。戻る操作も当該設定を復元する。騙り設定の変更UIは未実装で、現在の騙り互換設定は固定。追加時には `bluff_roles` もBoardのスナップショットへ保存し、再生時に当該時点の設定を渡す。進行済み共同分布への新制約は条件付けで適用し、生存人数から再配分しない。

CO必須は排他的selectorで固定せず、条件集合を保持する設計へ移行済み（現在対応する条件のみ）。例：定員到達CCOと霊結果黒でCOを併用する。旧 `none/counter/filled` 入力も読み取り互換として保全し、新しいフォームは条件集合を保存する。条件の成立は当該Boardの公開情報から評価し、条件の追加で既存条件を消さない。霊結果条件・能力結果枝の実装は後続で行う。

名称「戦略オプション」への変更は未確定。現段階では名称を変更しない。
