# 候補行動と公開支持の同一方針による評価

## 撤回と原因

以前の診断は、固定の仮profile Kで公開支持を作りながら、物理側だけを合法候補aへ変更していた。真狩人P1・生存P1/P2/P3・全狼がP1襲撃する仮方針ではGJ確率0。一方、狼P2の候補P3襲撃ではP1のP3護衛によるGJが起こる。異なる方針の混在によるゼロ支持であり、同じ方針に従って生成した未来が想定外になる証拠ではなかった。

この例から「①には追加信念ルールが必要」「未定義なので未実装として先送り」を導いた説明を撤回する。既存の実観測候補ゼロの想定外合意、機能未対応、計算予算とは区別する。4分類UI案は未採用で退避済み。

## 修正契約

戦略ルールは設定済みの継続戦略の下で合法手を比較し、最大の手を選ぶこと。候補手は決定前の戦略範囲内。各候補aに対して、WolfInformationの同じ役職roster/自身の行動履歴を持つ全世界で、同一の候補方針を使う。さらに、完全な公開入力・共同履歴のID置換で同じ情報集合/候補手になる行には同じ候補ルールを適用し、同等な対象の同点は均等に保つ。これにより、本人がどの候補を検討したかを公開側へ漏らさない。それ以外の行は元の完全profileのまま保持する。未知の真狩人・他者の占い結果や閲覧者の秘密を使って行を切り分けない。

共通フローの公開支持と物理枝をその同一候補方針へ揃える。これは候補の反実仮想評価で、実際の公開ログに行動選択の事実を加えない。入力のBoard/完全共同履歴を変更しない。Model AのQ、世界内秘密混合と物理質量は分離したままである。

通常rootの候補検証でも一時的に同じ完全候補方針を使い、finallyで復元する。cacheは完全な候補文脈を含める。ID置換はBoard・全共同履歴・情報集合roster/襲撃履歴・候補profileの対象/確率を同じ全単射で写す。異なるprofileを本人条件だけのcacheで混ぜない。

## 最小回帰の結果

本人の狼P2の行だけ変更する初回試行では1/2だったが、これは候補検討の本人位置が公開推論へ漏れるため採用しない。既存の既知狩人経路と照合し、P2→P3と対称なP3→P2も同一ルールで評価する。両護衛ルールで、候補P1襲撃の村勝率0、候補P3襲撃の村勝率1/4を未短縮の共通フローで確認。既知狩人の全9profileの探索も一意となり、従来の不一致由来の拒否は出ない。同じ狼情報集合内で隠れた狩人位置が異なっても候補方針は同一。公開履歴不変と、profile全体のID置換/異なるprofileの分離の回帰は成功。

候補profileの全探索は元の完全な集合を保持し、対称なprofileだけへの探索制限は採用しない。終端行の再利用も、変更後の候補profile全行から公開支持集合を計算する。

全597テストが281.683秒で成功。最後のキャッシュキーをより保守的にした後、関連36テスト（公開/本人・保存GJ・複数夜・両護衛ルール・未短縮の全候補照合を含む）が76.950秒で成功。最終再測定: C/H/W 5人は2401中50評価・19.994秒で予算未完、6人は759375候補・0.946秒でprobe予算未完。どちらもundefined issueなし。潜伏6人の占のみ20.353秒、霊のみ4.858秒、占霊20.549秒はroot_guard_profile_budget_unfinished。すべて既定予算を維持し、未証明の方針をcacheへ採用しない。①全体は未完のままである。予算未完を想定外と呼ばない。大きい昼max/夜maxのprofile証明を①の狼側最大化や将来の同時複数maxの完了条件に混同しない。新しいゲーム規則は採用せず、公開・push/deployは保留する。
