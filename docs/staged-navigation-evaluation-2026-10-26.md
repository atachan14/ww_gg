Value complete and action-detail complete remain distinct (certificate-only values do not claim complete action tables).

Save success and calculation failure are separate. Failure leaves the accepted Current/revision and role rates available with a retry button. A newer Current cancels the old read through the existing cooperative cancellation transport. A later draft cancel restores the latest committed value baseline, not the initial pending HTML. Details requests preserve details=1; public Q/P rules, manual zero-selection edges and policies are unchanged.
