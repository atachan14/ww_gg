# Publication continuation orbit audit and bounded prototype

The immutable-sharing experiment at 8383206 remains disabled. This checkpoint adds benchmark code and tests only: no normal UI, HELP, MAX policy, public edition, or production dispatch changes.

## Existing representation and the eager boundary

`CutOutUniformEngine.act` already evaluates a certified target-group representative and transports its scalar; day solving weights by group size. The joint-night forecast / two-night prototypes also have wolf-roster plus attack representatives, orbit masses, members and path mappings. Their certificates cover limited initial-night / seven-player intermediate scopes. The generic initial night still loops over wolf information groups and then targets; those prototypes are not a general initial-game dispatcher.

Publication generation has structural templates, but `restore` and `public_report_branches` restore named Boards before continuation backup. `InformationSetActionPolicy.morning_value` calls morning generation and mass transfer, then reconstructs and solves each positive-P labelled child. `record_publications` likewise creates named evidence eagerly. Existing publication certificates establish Q/history equivariance; they do not by themselves establish private P, physical state, or observer invariance.

## Minimal experiment

`cut_out_publication_orbit_value.py` evaluates representatives at one owned publication boundary. Future recursion uses the ordinary labelled engine. It only refines existing certified public groups, point-fixes observer/acquisition endpoints and known wolf roster endpoints, and checks generators against the complete private law and physical Board. A failed group becomes singletons. Unknown observers, guards, nonuniform policies and unsupported disclosure rules are declined. Owner, revision, source, proof context and evaluator settings are checked.

Per-label public Q probability, conditional Q/P laws and actual orbit chance mass remain separate. Multiplicity enters the common observer mass-transfer coefficients; it does not reweight the representative Q law. Value-only evaluation restores no named root Boards. Explicit detail requests transport full Q/P/history/physical state and target-indexed Forecast, and create ordinary evidence for cold restoration. Q-positive/P-zero hypothetical public detail uses PublicReportEvidence and does not invent normalized actual P.

## Limits and remaining work

The local roster case removes about one third of action evaluations, while asymmetric histories can remove none. No whole-initial-game completion or large global speed improvement is demonstrated. The earlier bounded initial search observed 55,801 publication templates versus 57,238 named vectors: many later stabilizers are small. This ratio is not a runtime bound, because pruning an early orbit can also remove descendants.

Production integration would require representative continuation backup throughout recursion, composition of publication maps with action/wolf maps and SavedOrigin evidence, and certificates for the relevant full private/physical/observer state at every boundary. Requested cold detail may still materialize named rows during evidence replay. The present prototype deliberately proves only one boundary and retains labelled future recursion. Existing MAX behavior is untouched; no new strategy or undisclosed optimal report rule is inferred.

Machine-readable evidence: `benchmarks/player_match_groups/publication-orbit-value-*-results.json` and `publication-orbit-value-tests.json`. No long initial search was run for this checkpoint.

## Recursive extension after e0b00ba

The same module now has an explicit `RecursivePublicationOracle`. It replaces only the common morning-value hook and reuses the original `PublicationOrbitValue` proof, common mass transfer and lazy output code. Existing inherited-group acquisition/action/publication transitions carry the public certificate forward. Targets and wolf information are still evaluated by ordinary labelled actions; this is not a new general canonical-state cache.

At every later morning the exact owned source receipt, full Q and private P, physical state, known observer endpoints, and uniform/full-seer-disclosure policy conditions are checked again. Blocks only split. Preflight refusal returns to the ordinary morning implementation with the same configured strategy; missing optional transition proofs leave no certificate for later compression. Failed mass transfer, zero support and continuation errors propagate and are never replaced by fallback or uniform completion. Evidence snapshots use ordinary transitions and do not mutate the live proof registry.

For requested output, `labelled_descendant` composes the certified outer report-label map with later ordinary action/report observations. It creates actual mapped ActionEvidence/PublicationEvidence and replays from the original SavedOrigin. There is no synthetic final-state transport receipt. Unknown intervening operations (including arbitrary conditioning operations) are refused; generic mixed-operation path transport remains unsupported and must use ordinary reconstruction.

### Interpretation and remaining scope

A representative branch can remain in its label frame across common actions and later publication boundaries, with renewed certificates and explicit output-map composition. This is now demonstrated locally across D2 and D3, including a fixed private observer. It is not evidence of a useful whole-initial performance improvement. Later history breaks most symmetry, and full-law checks, repeated receipt reconstruction and audit retention cost more than the few remaining reductions save. Before further expansion, the useful next design question is whether existing inherited transition proofs can cheaply certify the full private stabilizer without repeatedly reconstructing complete sources; replacing those checks requires a new sound certificate, not role-marginal heuristics.

The ordinary UI, HELP, MAX logic, public edition and server processes remain unchanged. No push/deploy. Machine-readable extension evidence is in `publication-orbit-recursive-*-results.json`, `publication-orbit-recursive-tests.json` and the explicitly unverified exhaustive artifact.
