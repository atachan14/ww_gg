## Exploratory decision, with the magnitude limitation retained

The original script recorded an additional5% minimum Forecast effect-size gate for BOTH cases. The six-player case passed; seven-mid did not (4.2%). This false result is retained verbatim in compact-terminal-alternating-results.json and original_5pct_effect_gate_passed=false in the matched-work record. It was not rewritten as a pass.

Four paired improvements in each case, exact contents and no material endpoint time/memory regression supported only a short exploratory fixed-work measurement under the user's conditional authorization. This does not turn the failed5% magnitude gate into evidence of a broadly material effect or authorize adoption/full initial search. The distinction between directional stability and minimum effect size is explicit in the second driver's decision field.
